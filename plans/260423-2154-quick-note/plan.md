# Plan: Quick Note Feature
Created: 2026-04-23
Status: 🟡 In Progress

## Overview
Tính năng Ghi chú nhanh (Quick Note) cho phép nhân viên thêm ghi chú vào Hợp đồng trực tiếp từ khu vực "Thao tác nhanh" (Quick Actions Grid) thông qua một popup Modal gọn gàng, thay vì phải kéo xuống tận phần `NotesTimeline` bên dưới.

## Tech Stack
- Frontend: Next.js (React), TailwindCSS, Lucide React (Icons)
- Backend: Server Actions (`addContractNote`) có sẵn
- Component: Modal tái sử dụng chuẩn Apple HIG
