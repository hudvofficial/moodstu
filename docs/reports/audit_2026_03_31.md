## 🔴 Critical Issues (Phải sửa ngay - Vi phạm Architecture)

### 1. Lạm dụng Inline Tailwind thay vì dùng CSS Tokens (Layout & Spacing)
- **Vị trí:** `components/services/form/index.tsx` và `ServiceBundleSection.tsx`
- **Nguy hiểm:** Code rất rối, khó bảo trì. Re-render UI dễ bị lệch khi trên Mobile vs Desktop vì không dùng chung một "Quy chuẩn Layout" (CSS Token) mà code tay cực kỳ dài.
- **Ví dụ vi phạm:** `max-w-6xl mx-auto pb-32 lg:pb-12 lg:grid lg:grid-cols-12 lg:gap-8 items-start`, `flex-col sm:flex-row justify-between items-start sm:items-center`
- **Cách sửa:** Gộp các class lằng nhằng này thành các CSS Tokens trong `components.css` như `.layout-page-split`, `.flex-between-responsive`, v.v.

### 2. Logic Data Fetching nằm chung ở UI (Missing Hooks)
- **Vị trí:** `ServiceBundleSection.tsx` (Dòng 28-50)
- **Nguy hiểm:** Viết trực tiếp `useEffect` và `getServices` (gọi API) ngay trong giao diện UI. Nếu sau này cần dùng logic search này ở trang khác thì phải copy-paste lại.
- **Cách sửa:** Tách toàn bộ logic tìm kiếm dịch vụ ra một Custom Hook riêng, ví dụ: `hooks/useServiceSearch.ts`. UI chỉ việc gọi `const { results, search } = useServiceSearch()`.

### 3. Thiếu Shared Components (Nhiều code tự chế, lặp lại)
- **Vị trí:** Quanh form `index.tsx`, `ServiceBundleSection.tsx`
- **Nguy hiểm:** Dùng thẳng thẻ `<button className="btn-primary">` thay vì dùng component chuẩn `<Button variant="primary">`. Viết tay ô search thay vì dùng một Shared Component `SearchInput`. Điều này làm mất tính đồng bộ của hệ thống.
- **Cách sửa:** Sử dụng các thành phần từ thư mục Shared Components (e.g. `components/ui/button.tsx`, `components/ui/search-input.tsx`).

## 🟡 Warnings (Nên sửa)

### 1. Hardcode Mobile / Desktop Save Button lặp lại
- **Vị trí:** `index.tsx` 
- **Vấn đề:** Nút "Lưu" đang bị code 3 lần khác nhau cho 3 màn hình (Điện thoại, Desktop Sidebar, Mobile Sticky Bar) với cùng một logic.
- **Cách sửa:** Chuyển cụm nút lưu thành `<SaveActionButtons isEditMode={isEditMode} />`.

### 2. Xử lý State của mảng Bundle Array có rủi ro
- **Vị trí:** Hàm `updateBundleItem` trong `ServiceBundleSection.tsx`
- **Vấn đề:** Thay đổi state array bằng index có thể dễ gây lỗi hiển thị nếu thứ tự mảng bị thay đổi (kéo thả).
- **Cách sửa:** Nên dùng ID để update thay vì index.

## 🟢 Suggestions (Tùy chọn)
1. **Lazy Load Modal:** `CategoryManagerModal` đang được mount sẵn ngay khi load form, nên dùng dynamic import (lazy loading) để giảm dung lượng file Javascript lúc đầu.
2. **Animation cho List:** Thêm `framer-motion` hoặc transition của Tailwind cho mượt khi "Thêm / Xoá" Bundle Item nhé.
