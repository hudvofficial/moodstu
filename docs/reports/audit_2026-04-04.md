## 🟡 Warnings (Nên sửa)

1. **Performance: N+1 / Multiple Queries trong `getContractOptions`**
   - File: `app/actions/printing-queries.ts` (Dòng 322)
   - Vấn đề: Khi user gõ tìm kiếm Hợp đồng, code đang chạy 2 query song song (tìm theo mã HĐ và tìm theo tên khách hàng), sau đó chạy thêm 1 query thứ 3 để lấy contracts từ list danh sách khách hàng. Điều này làm app chậm đi khi search.
   - Cách sửa: Sử dụng 1 query duy nhất trên Supabase bằng PostgREST filter: `.or('contract_code.ilike.%xxx%, customers.full_name.ilike.%xxx%')` với `.select('..., customers!inner(...)')`.

## 🟢 Suggestions (Tùy chọn)

1. **Business Logic: Auto-update Contract Status**
