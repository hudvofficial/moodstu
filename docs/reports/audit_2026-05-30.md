## 🔴 Critical Issues (Phải sửa ngay)
1. **Hydration Mismatch trên SplashScreen**
   - File: `components/layout/splash-screen.tsx`
   - Nguy hiểm: Component `<SplashScreen>` sử dụng `next/image` (`<Image />`) chung với điều kiện render phía Client, gây ra lỗi Hydration (như trong màn hình báo lỗi). Lỗi này có thể làm vỡ giao diện trong tích tắc khi Next.js cố gắng đồng bộ SSR và CSR.
   - Trạng thái: **Đã tự động sửa (Auto-fixed)** bằng cách thay `<Image />` thành native `<img>` tag để ngăn Next.js tự động inject thêm các props khác nhau trên Server và Client.

## 🟡 Warnings (Nên sửa)
1. **JS Loop Aggregation - Tính toán dữ liệu ở tầng Server Node.js thay vì Database RPC**
   - File: `app/actions/finance-dashboard-queries.ts`
   - Vấn đề: Các hàm tính toán báo cáo (ví dụ: gộp doanh thu theo tháng) đang sử dụng vòng lặp `for` trong JavaScript (`for (const row of payments.data) byMonth[...] += row.amount`). 
   - Lý do: Vi phạm chuẩn V2 ENFORCEMENT ("Mọi logic phức tạp, data aggregation phải tống xuống Supabase RPCs"). Tính toán trên Node.js có thể gây chậm khi dữ liệu lớn.
   - Cách sửa: Chuyển logic GROUP BY và SUM xuống PostgreSQL function (Supabase RPC) để tăng tốc và giảm tải băng thông.
